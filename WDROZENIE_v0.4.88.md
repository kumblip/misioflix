# Wdrożenie v0.4.88

Wgraj pełną paczkę źródłową do repozytorium GitHub i uruchom dotychczasowy workflow.
Po zielonej kompilacji, instalacji wydania i restarcie Jellyfina sprawdź w natywnym odtwarzaczu przejście `S01E21 -> S01E22 -> Wstecz`. Powinno otworzyć sezon E22 bez dodatkowego przeładowania strony. Następnie wróć do biblioteki i przewiń ponad 100 pozycji bez Ctrl+F5.
Nie przeprowadzono testu na NAS-ie ani lokalnej kompilacji .NET 10.
