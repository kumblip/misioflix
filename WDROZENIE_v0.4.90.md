# Wdrożenie v0.4.90

1. Prześlij pełną paczkę źródeł do GitHub albo pliki z paczki różnicowej, zachowując ścieżki.
2. Uruchom GitHub Actions (dotnet publish). W lokalnym środowisku nie ma .NET 10, więc kompilacja DLL nie została potwierdzona.
3. Zainstaluj Release, zrestartuj Jellyfin i wykonaj Ctrl+F5.
4. Sprawdź kafelki filmów/seriali z kolekcji na stronie głównej oraz w bibliotekach, zwłaszcza liczbę pozycji i ikonę 📦 pod łapkami.
5. `Jellyfin_Wlasny_CSS.txt` umieść w repozytorium jako dokumentację; to nie jest domyślny CSS wtyczki. Nie nadpisuj istniejącego własnego CSS Jellyfina, jeśli używasz także innych reguł.
